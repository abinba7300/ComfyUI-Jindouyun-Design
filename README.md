# 筋斗云设计 ComfyUI 节点包

这是一个用于 ComfyUI 的“筋斗云设计”功能节点包。

## 安装

进入 ComfyUI 的 `custom_nodes` 目录后执行：

```bash
git clone https://github.com/abinba7300/ComfyUI-Jindouyun-Design.git comfyui-jindouyun-design
```

重启 ComfyUI，然后在节点搜索中输入“筋斗云”。本节点包的基础功能不需要额外安装 Python 依赖。

更新节点包：

```bash
cd comfyui-jindouyun-design
git pull
```

## 节点总览

- `筋斗云随机LORA`：随机或固定加载 LoRA，只应用到模型并输出触发词和参数摘要
- `Nunchaku 随机 LoRA`：面向 Nunchaku FLUX 模型的随机 LoRA 加载器
- `筋斗云画布合成`：画布排版、图片合成、全屏绘画、图层和自由变换
- `筋斗云交互裁剪`：节点内可视化裁剪、旋转、镜像、缩放和尺寸判断
- `筋斗云透明裁切`：裁掉透明图四周多余空白
- `筋斗云图像尺寸判断`：根据判断信号切换符合尺寸或不符合尺寸的图像路线
- `筋斗云-显示任何`：显示并原样传递任意类型数据
- `筋斗云-提示词`：根据 LoRA 名称中的用户关键词自动切换并拼接多段提示词方案
- `筋斗云数值滑块`：可命名、可配置范围和步进、可自定义颜色的 FLOAT 滑块

> `Nunchaku 随机 LoRA` 需要另外安装并启用 ComfyUI-nunchaku。其他节点不依赖 Nunchaku。

## 工作流历史备份

- 每次手工保存工作流时，先自动备份覆盖前的旧版本
- 支持保存按钮、`Ctrl+S` 和“另存为”操作；自动保存与排队运行不会产生备份
- 每个工作流独立保留最近 20 个保存时间点，超过后自动删除最旧版本
- 备份保存在当前 ComfyUI 用户目录的 `.jindouyun-workflow-backups` 文件夹，刷新页面和重启后仍然存在
- 点击网页右下角的绿色 `快速保存`，可以立即保存当前工作流并记录一个历史版本；旁边的 `工作流历史` 可以查看、加载、重命名或删除最近 20 个版本
- 加载历史只会放到当前画布，不会立即覆盖主文件；确认无误后再手工保存

## 节点

### 筋斗云画布合成

- 全屏绘画支持可手工开启的 `智能规整`，自动识别并规整近似直线、圆形、椭圆和圆弧；默认关闭
- `识别灵敏度` 默认 50%，调高更容易规整，调低则更谨慎地保留自由笔画
- 规整结果保存为独立绘画图层，支持撤销、移动、缩放、旋转、镜像和最终图片输出

### 筋斗云随机LORA

搜索：

```text
筋斗云随机LORA
```

输出：

- `模型`：已经应用所选 LoRA 的模型
- `触发词`：所选 LoRA 对应的触发词
- `LoRA名称`：当前选中的 LoRA 文件名

## 触发词规则

默认触发词取 LoRA 文件名第一个 `-` 前面的文字。如果文件名里没有 `-`，再取第一个 `_` 前面的文字。

示例：

```text
shuhuifengge-K2T-V1_copy_000010500.safetensors -> shuhuifengge
qichefengge-K2T-v1_000007200.safetensors -> qichefengge
```

不需要手动填写映射表，节点会自动从当前随机到的 LoRA 文件名里提取触发词。

## 文件夹

`LoRA目录` 留空时，会使用 ComfyUI 的第一个 `models/loras` 文件夹。也可以输入绝对路径，或者输入 `models/loras` 下面的子文件夹名称。

开启 `随机模式` 后，改变 `随机种子` 就会切换随机选中的 LoRA。

`固定` 只在关闭 `随机` 时使用，用来指定固定加载某一个 LoRA。

`过滤` 用来缩小随机范围。比如填 `K2T`，就只会在文件名包含 `K2T` 的 LoRA 里随机；留空就是文件夹里全部 LoRA 都参与随机。

### 筋斗云画布合成

搜索：

```text
筋斗云画布合成
```

功能：

- 自定义画布宽度和高度
- 选择常用比例预设，例如 `1:1`、`3:4`、`4:3`、`16:9`、`9:16`、`21:9`
- 设置背景颜色，默认白色
- 支持图层和画布混合模式，例如 `normal`、`multiply`、`screen`、`overlay`、`difference`
- 支持透明度控制
- 输入图像默认居中放到画布上
- 可用 `图片X`、`图片Y`、`图片缩放` 精确控制位置和大小
- 前端会显示一个可拖动的定位画布，预览框会按输入图像比例显示，靠近中心时会自动吸附并显示中心线
- 全屏绘画支持自定义色盘与画布吸管；吸取颜色后自动切回画笔，并保存为可重复使用的圆形色块
- 图片可通过四角抓手等比例放大到画布之外；超出部分由画布裁切，居中和贴边规则保持不变
- 输出合成后的 `IMAGE`

### 筋斗云透明裁切

搜索：

```text
筋斗云透明裁切
```

功能：

- 接收 `IMAGE`，可选接收 `MASK`
- 按透明通道或遮罩自动裁掉四周多余空白
- `透明阈值` 用来控制哪些像素算可见
- `保留边距` 可以在主体周围保留指定像素边距
- `启用裁切` 关闭时会原样输出图像和遮罩
- 输出裁切后的 `IMAGE` 和对应 `MASK`

适合接在抠图、背景移除节点后面，再接 `筋斗云画布合成` 或其它图像节点。

### 筋斗云交互裁剪

搜索：

```text
筋斗云交互裁剪
```

功能：

- 可直接上传图片，也可连接上游 `IMAGE`；连接上游时优先使用上游图像
- 图片和裁剪框直接显示在节点内，不需要打开全屏界面
- 自由比例支持拖动裁剪框、八方向调整大小，以及在框外重新框选
- 固定比例支持 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`，拖动四角时保持比例
- 实时显示最终输出像素尺寸
- `最大边缩放` 默认关闭，此时保留裁剪和变形后的实际分辨率
- 开启后可填写目标最大边分辨率；输入 `0` 表示不改变当前尺寸
- 支持高质量放大和缩小，短边会根据裁剪比例自动计算
- `双三次 bicubic（推荐·通用）`：照片、产品图和透明素材的稳定默认选择
- `Lanczos（推荐·清晰锐利）`：边缘更锐利，适合最终成图
- `区域 area（推荐·缩小）`：主要用于缩小图片，结果干净稳定
- `双线性 bilinear（快速）`：速度快，适合预览和普通缩放
- `最近邻 nearest-exact（像素画/蒙版）`：保持硬边，不产生中间颜色
- 支持旋转：可拖动预览画布顶部中央的橙色手柄进行任意角度旋转，也可输入精确角度；点击“归零”恢复 `0°`
- 旋转后画布会自动扩展，四角保留透明区域；`0°` 时与旧版裁剪行为兼容
- 支持一键左右镜像、上下镜像，两个方向可以同时启用
- 图像按“镜像 → 旋转 → 裁剪 → 最大边缩放”的顺序处理
- 松开鼠标后自动保存裁剪区域并输出真实裁剪结果

### 筋斗云图像尺寸判断

搜索：

```text
筋斗云图像尺寸判断
```

功能：

- 接收“符合尺寸图像”和“不符合尺寸图像”两路输入
- 接收对应的两个布尔判断信号
- 根据判断结果只输出当前应该继续执行的一路图像
- 适合与“筋斗云交互裁剪”的尺寸判断信号配合使用

### 筋斗云-显示任何

搜索：

```text
筋斗云-显示任何
```

功能：

- 接收任意类型内容并在节点内显示
- 默认使用普通字号，可按需开启三倍文字放大
- 显示区域会跟随节点宽度和高度变化
- 输出内容保持原类型和原数值不变

### 筋斗云-提示词

搜索：

```text
筋斗云-提示词
```

功能：

- 把“筋斗云随机LORA”的 `LoRA名称` 输出连接到节点输入
- 每套方案默认提供三个多行文本框，文本段和方案都可以动态增加或删除
- 每套方案可以填写一个或多个关键词，每行一个；例如分别填写 `V1.1` 和 `V1.0`
- 匹配时从实际 LoRA 名称中查找关键词，忽略英文大小写，但不进行模糊、相似度、触发词或提示词推断
- `DEMO-STYLE-LORA-V1.1_000004000.safetensors` 会进入 `V1.1` 方案，`DEMO-STYLE-LORA-V1.0_000004600.safetensors` 会进入 `V1.0` 方案
- 空文本段自动跳过，可自定义拼接分隔符
- 可指定默认方案；没有关键词匹配时使用默认方案，没有默认方案时输出空字符串
- 方案名称完全由用户手工命名；连接或运行 LoRA 都不会覆盖方案名称
- LoRA 关键词、方案名称和提示词内容都会自动保存，无需再点击保存按钮
- 方案下拉框直接显示“关键词 → 提示词方案”，固定 LoRA 会实时显示预计分流，随机 LoRA 会在运行后显示实际命中的关键词和方案
- 同时命中多个方案时按方案列表顺序使用第一个，并在状态牌显示冲突提示
- 旧工作流中的完整 LoRA 名称绑定会继续作为长关键词使用
- 最终只输出一个 `STRING`，用于连接正向提示词或其它文本节点

### 筋斗云数值滑块

搜索：

```text
筋斗云数值滑块
```

功能：

- 自定义滑块名称，也可以将名称留空
- 设置当前值、最小值、最大值和步进值，默认步进为 `0.05`
- 拖动时严格按步进吸附，并可直接输入精确数值
- 通过色盘或十六进制色号自定义滑块颜色
- 输出标准 `FLOAT`，可连接 LoRA 强度、重绘值、CFG 等数值参数

## 兼容性

- 支持 ComfyUI 的标准 `MODEL`、`IMAGE`、`MASK` 和 `FLOAT` 数据类型
- 标准随机 LoRA 节点可用于与模型架构匹配的 SDXL、FLUX、Krea2 等 LoRA
- Nunchaku 专用节点需要 ComfyUI-nunchaku 提供对应模型加载器
