# 筋斗云设计 ComfyUI 节点包

面向图像设计工作流的 ComfyUI 自定义节点包，集成 LoRA 加载、画布绘制、交互裁剪、图像浏览与保存、提示词分流和工作流版本管理。

## 安装

在 ComfyUI 的 `custom_nodes` 目录执行：

```bash
git clone https://github.com/abinba7300/ComfyUI-Jindouyun-Design.git comfyui-jindouyun-design
```

重启 ComfyUI，在节点搜索中输入“筋斗云”。基础功能不需要额外安装 Python 依赖。

更新：

```bash
cd comfyui-jindouyun-design
git pull
```

## 节点

| 节点 | 主要用途 |
| --- | --- |
| `筋斗云随机LORA` | 随机或固定加载 LoRA，仅作用于模型，并输出触发词、LoRA 名称和随机参数 |
| `Nunchaku 随机 LoRA` | 为 Nunchaku FLUX 模型随机或固定加载 LoRA |
| `筋斗云画布合成` | 图片排版、画布合成、全屏绘画、图层和自由变换 |
| `筋斗云交互裁剪` | 节点内框选裁剪，并支持旋转、镜像、比例、变形和分辨率处理 |
| `筋斗云透明裁切` | 自动裁掉透明图四周的空白区域 |
| `筋斗云-加载图像` | 浏览文件夹图片，快速切换上一张/下一张，并输出名称和路径 |
| `筋斗云-保存图像` | 保存到自定义目录，预览、切换和删除最近图片，快速打开文件夹 |
| `筋斗云图像尺寸判断` | 根据尺寸判断信号选择对应的图像路线 |
| `筋斗云-提示词` | 按 LoRA 名称关键词自动切换并拼接提示词方案 |
| `筋斗云-显示任何` | 显示并原样传递任意类型数据，可选三倍文字显示 |
| `筋斗云数值滑块` | 自定义名称、范围、步进和颜色的 FLOAT 滑块 |

## 网页工具

- `快速保存` 与 `工作流历史`：每个工作流保留最近 20 个手工保存版本，可加载、重命名、备注或删除。
- `重启 ComfyUI`：在网页右下角直接重启服务。

## 使用提示

- LoRA 触发词默认取文件名第一个 `-` 前的文字；没有 `-` 时取第一个 `_` 前的文字。
- `筋斗云-提示词`按用户填写的关键词进行字面匹配。例如 `DEMO-STYLE-LORA-V1.1_000004000.safetensors` 可匹配关键词 `V1.1`。
- 标准随机 LoRA 节点可用于 SDXL、FLUX、Krea2 等架构，但 LoRA 必须与当前基础模型匹配。
- `Nunchaku 随机 LoRA` 需要另行安装并启用 `ComfyUI-nunchaku`。

## 兼容性

支持 ComfyUI 标准 `MODEL`、`IMAGE`、`MASK`、`STRING` 和 `FLOAT` 数据类型。
