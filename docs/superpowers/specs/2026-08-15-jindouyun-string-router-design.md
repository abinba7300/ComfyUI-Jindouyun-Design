# 筋斗云-字符串节点设计

## 目标

用一个节点替代多组文本节点、文本拼接节点和文本切换节点。节点根据“筋斗云随机LORA”输出的实际 LoRA 名称信号，精确选择一套文本方案，并把该方案内的多段文本拼接成一个字符串输出。

文本内容不参与匹配。触发词是否相同、文本中是否包含 LoRA 名称，都不会影响切换结果。

## 节点接口

- 节点名称：`筋斗云-字符串`
- 输入连接点：`LoRA名称`，类型为 `STRING`
- 输出连接点：`字符串`，类型为 `STRING`
- 分类：`筋斗云设计/文本`

应连接“筋斗云随机LORA”的 `LoRA` 输出，而不是 `触发词` 或 `组合名` 输出。

## 方案编辑器

- 新建节点默认包含一个方案，每个方案默认有三个多行文本框。
- 顶部提供方案选择器，并提供“新增方案”和“删除方案”按钮。
- 每个方案包含：方案名称、已绑定 LoRA 列表、多段文本、拼接分隔符和“设为默认方案”开关。
- 提供“新增文本段”和“删除文本段”按钮；每套方案至少保留一个文本框，最多十二个。
- 空文本段自动跳过，默认分隔符为英文逗号加空格 `, `。
- 多个 LoRA 可以精确绑定到同一方案，同一个 LoRA 只能绑定到一个方案；新绑定会从旧方案移除，避免歧义。
- 节点宽度保持紧凑，只显示当前正在编辑的方案，其他方案通过选择器切换。

## LoRA 绑定与匹配

- 运行时后端将收到的 `LoRA名称` 原样作为信号，并仅做首尾空格和路径分隔符标准化。
- 精确绑定优先使用完整相对路径；没有路径时使用不带 `.safetensors` 后缀的完整文件名。
- 不根据触发词、文件名前缀、关键词或文本内容进行模糊猜测。
- 前端记录最近一次运行收到的 LoRA 名称，当前方案提供“绑定当前 LoRA”按钮。
- 用户也可在绑定列表中手工输入完整 LoRA 名称，用于尚未随机到的文件。
- 若没有精确命中，使用被标记为默认的方案；未设置默认方案时输出空字符串。

## 运行反馈

- 节点顶部显示运行状态牌。
- 精确命中时显示绿色状态：`已匹配：方案名称`。
- 使用默认方案时显示蓝色状态：`未匹配，使用默认方案`。
- 无匹配且无默认方案时显示粉色描边状态：`未找到绑定方案`。
- 状态牌只显示运行结果，不参与工作流参数序列，避免旧工作流参数错位。

## 保存与兼容

- 所有方案保存在一个隐藏的 JSON 字符串控件中，随 ComfyUI 工作流保存。
- JSON 使用稳定的方案 ID 和文本段 ID；增删方案或文本段不会让其他内容错位。
- 后端对缺失字段、旧版本字段、损坏 JSON 和重复绑定进行容错，并返回可预测结果。
- 前端不可用时仍保留原生 JSON 控件作为恢复入口，不阻断工作流执行。

## 测试

- 后端测试覆盖精确匹配、相同触发词但不同文件名、多 LoRA 绑定同一方案、默认方案、空文本段、分隔符和损坏配置。
- 前端测试覆盖默认三段文本、增删方案、增删文本段、绑定当前 LoRA、重新加载工作流和状态牌刷新。
- 集成测试确认节点可直接接收“筋斗云随机LORA”的 `LoRA` 输出，并只产生一个字符串输出连接点。
