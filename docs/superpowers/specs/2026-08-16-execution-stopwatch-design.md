# 筋斗云任务秒表设计

## 目标

在 ComfyUI 工作界面提供常驻悬浮数字秒表，准确显示每个任务从开始执行到成功、失败或中断的耗时；成功完成时播放一次短促的“叮”声。

## 交互

- 默认位于工作区右上角，支持拖动，并通过 `localStorage` 记住位置。
- 空闲时显示上一次结果；运行时以 `MM:SS.cc` 实时计时。
- 运行中使用橙色状态，成功使用绿色，失败或中断使用红色。
- 提供紧凑的声音开关，默认开启并记住用户设置。
- 新任务开始时自动归零；任务结束后保留本次耗时，直到下一次任务开始。

## 技术方案

- 使用纯前端扩展监听 ComfyUI 的 `execution_start`、`execution_success`、`execution_error` 和 `execution_interrupted` 事件。
- 使用 `performance.now()` 和 `requestAnimationFrame()` 计算与刷新耗时，避免系统时间调整造成跳变。
- 使用 Web Audio API 合成短促衰减铃声，不增加外部音频文件或后端依赖。
- 以 `prompt_id` 关联开始和结束事件，忽略不属于当前任务的迟到事件。

## 异常处理

- 浏览器尚未允许音频时，等待首次鼠标或键盘交互解锁音频；音频失败不影响计时。
- 页面尺寸变化时将悬浮窗约束在可视区域内。
- 重复加载扩展时不重复创建悬浮窗或绑定事件。

## 验证

- 单元测试覆盖时间格式、任务开始、结束、错误和错误任务 ID 忽略逻辑。
- 前端源测试覆盖四类执行事件、拖动位置记忆、静音设置和 Web Audio 铃声。
