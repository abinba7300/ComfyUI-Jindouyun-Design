# 筋斗云交互裁剪侧边工具栏设计

## 目标

将旋转、镜像和变形操作从裁剪画框上方移到画框两侧，减少顶部参数堆叠，并利用画框左右的空余区域。

## 布局

- 顶部保留最大边缩放、分流标准和裁剪比例。
- 画框左侧竖排旋转角度、左转 90 度、右转 90 度、归零、左右镜像和上下镜像。
- 中间保留交互裁剪画框以及原有裁剪、旋转和变形抓手。
- 画框右侧竖排长宽比锁定、变形重置、宽度比例和高度比例。
- 状态栏横跨三列并保持在画框下方。

## 约束

- 不改变旋转、镜像、变形和裁剪的数据逻辑。
- 两侧工具栏不得超出节点边界或遮挡裁剪画面。
- 控件保持中文，按钮使用短文字和清晰图标。
- 节点宽度变化时，中间画框优先伸缩；两侧工具栏保持稳定宽度。
- 保留当前画框高度和鼠标交互精度。

## 验证

- 前端源码测试验证控件已挂载到左右侧栏，不再位于顶部。
- 完整 JavaScript 与 Python 测试必须通过。
- 在本机 ComfyUI 中检查顶部更简洁、两侧无越界、中央画框可正常交互。
