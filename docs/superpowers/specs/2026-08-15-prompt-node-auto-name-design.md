# 筋斗云提示词节点自动命名设计

## 目标

把“筋斗云-字符串”显示名称改为“筋斗云-提示词”，把“筋斗云随机LORA”的 `LoRA` 输出名称改为 `LoRA名称`，并让提示词方案在收到上游 LoRA 名称时自动同步名称。

## 自动命名

- 固定 LoRA 模式连接到提示词节点后，前端读取上游节点当前的固定 LoRA 选择，无需排队即可同步当前方案名称。
- 随机 LoRA 模式在连接时尚无本次随机结果；界面显示已经连接，并提示运行后获取名称。
- 每次工作流运行后，提示词节点从后端 `lora_name` UI 数据取得真实 LoRA 名称并自动同步方案名称。
- 有关键词命中时更新第一个命中的方案；没有关键词命中时更新当前正在编辑的方案。
- 自动命名只修改方案名称，不修改关键词、文本段、分隔符或默认方案。
- 保留“记录当前 LoRA”按钮作为手工重新同步入口。

## 名称调整与兼容

- `JindouyunRandomLora.RETURN_NAMES` 的第三个名称改为 `LoRA名称`，返回值顺序和类型不变，因此现有连线继续使用原插槽。
- `JindouyunStringRouter` 的注册键和 Python 类名保持不变，只将显示名称改为 `筋斗云-提示词`，旧工作流继续加载同一节点。
- 搜索别名同时保留“筋斗云-字符串”和“筋斗云字符串”，并新增“筋斗云-提示词”。
- 节点输入仍名为 `LoRA名称`，输出仍为 `字符串`。

## 连接状态

- 未连接：显示“等待 LoRA 名称信号”。
- 已连接固定模式：立即显示读取到的固定 LoRA 名称，并同步当前方案。
- 已连接随机模式但尚未运行：显示“已连接，运行后获取随机 LoRA 名称”。
- 运行后：继续显示关键词匹配、默认方案、未匹配或冲突状态，并同步目标方案名称。

## 测试

- 验证随机 LoRA 第三个输出名称为 `LoRA名称`，输出顺序和类型没有变化。
- 验证节点显示名称为“筋斗云-提示词”，注册键仍为 `JindouyunStringRouter`。
- 验证固定模式连接数据可立即归一化并同步当前方案。
- 验证运行后按关键词命中的方案自动同步；未命中时同步当前方案。
- 验证自动同步不会修改关键词和文本内容。
- 验证旧工作流配置和现有连接可继续执行。
