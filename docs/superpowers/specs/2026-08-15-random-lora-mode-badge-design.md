# 筋斗云随机 LoRA 模式状态牌设计

## 目标

在“筋斗云随机LORA”节点顶部加入一眼可辨的模式状态牌，解决原有小开关不易识别当前模式的问题。

## 交互与视觉

- 状态牌固定为整行、约 48 像素高，不增加节点宽度。
- 随机目录模式使用绿色描边与低透明绿色背景，左侧显示“随”图标块，主标题为“随机目录模式”，副标题为“目录内全部 LoRA · 每次随机 1 个”。
- 固定单文件模式使用蓝色描边与低透明蓝色背景，左侧显示“固”图标块，主标题为“固定 LoRA 模式”，副标题显示当前固定 LoRA 文件名；未选择时显示“尚未选择固定 LoRA”。
- 点击状态牌直接切换模式；状态牌复用原“随机”控件自身，不再额外创建控件。
- 状态牌不遮挡节点连接点，也不在 `widgets_values` 中增加占位值。

## 数据流

状态牌直接改写现有“随机”布尔控件的绘制和点击行为，并读取“固定”控件用于副标题。切换时调用原控件回调并刷新 ComfyUI 画布，因此后端执行逻辑保持不变。

## 兼容与测试

- 仅应用于 `JindouyunRandomLora`，不改变旧版节点和 Nunchaku 节点外观。
- 加载旧工作流时自动移除历史 DOM 状态牌曾保存的首位空占位，恢复正确的参数顺序。
- 新建节点、加载旧工作流、点击状态牌和修改固定 LoRA 时都刷新显示。
- 自动化测试覆盖颜色、文字、点击切换及原控件同步。
